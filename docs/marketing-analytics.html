Google Analytics 4 data from TRI website. Separating the audience between converters and non-converters using BigQuery export.

Users were viewing TRI's site however there were not many who stayed to sign up for trainings or donations.

The Trauma Resource Institute specializes with healthcare professionals, but also anyone interested in learning more about trauma and coping.

How can TRI platform their website to encourage more conversions? Which channels contribute most to conversion?

Markov Chain attribution, Shapley value analysis, first-touch vs last-touch comparison, path length analysis using R.

Visualizations

Key Findings

  1. All four channels matter. Markov and Shapley models show roughly equal contribution (~20–22 credits each).
  2. Mobile and Paid Search are structurally essential. Removing either causes the largest drop in conversion probability (~68%).
  3. Social Media is undervalued by heuristics. The Markov model lifts it to near-parity (19.5 credits), suggesting an important mid-funnel role.
  4. Longer journeys convert better. Users with more touchpoints have higher conversion rates.

Recommendation: Use the Markov model as the primary attribution framework and Shapley values as a fairness check.
